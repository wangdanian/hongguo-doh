# 红果短剧 · 核心广告域黑名单（core）
# ============================================================
# 这份名单**常开生效**，不依赖 App 会话判定。
# 只放「红果 / 番茄阅读系专属」的广告位 —— 也就是别的 App 根本不会查的域名。
# 效果：任何 App 都不会被这份名单影响，因为它查不到这些域。
#
# 跨 App 通用的广告联盟（穿山甲、百度联盟、巨量、火山引擎 MSSDK）
# 已全部移到 blacklist-shared.txt —— 那份只在「红果会话窗口」内生效。
#
# 为什么要用 ** ：
#   App 会缓存 CNAME 链，之后直接解析别名拿真实 IP。
#   例如 ads3-normal-lq.zijieapi.com 的别名是
#       ads3-normal-lq.zijieapi.com.w.cdngslb.com
#   只拦原域名会被架空，必须用 ** 连带覆盖 CNAME 目标。
#   注意 ** 会跨点匹配，只加在很确定的广告域上。
# ============================================================
