# ============================================================
# 红果短剧去广告 —— 白名单（防误伤兜底）
# ============================================================
# 语义：**白名单优先于黑名单**。命中本文件的域名永不拦截。
#
# 为什么需要它：
#   DNS 拦的是域名，不是 App。同一个域名被多个 App 共用时，
#   无法只拦其中一个。2026-09-20 拦了 `h-adashx.ut.taobao.com`
#   和 `adashx4yt.m.taobao.com` 之后，淘宝 H5 页面等 ut 埋点通道
#   返回而卡死不渲染 —— 那就是"淘宝图片加载不出来"的真实原因。
#   第 8 组规则因此整组停用。
#
#   但停用只解决了当下。只要黑名单里再出现一条宽泛规则
#   （比如 `*taobao*`、`**umeng**`），同样的故障会立刻复发。
#   本文件是那道保险：关键功能域在这里，无论黑名单怎么改都放行。
#
# 语法（与 blacklist.txt 完全一致）：
#   abc.com        匹配 abc.com 及其所有子域
#   *-ad.x.com     *  不跨点
#   ads3.x.com**   ** 跨点，连带覆盖 CNAME 别名
#
# ⚠️ 加条目纪律：
#   只加【纯功能域】。绝不能把混着广告的父域加进来，否则等于
#   把广告一起放行。反例（禁止添加）：
#     zijieapi.com    -> ads3/ads5/ad.* 全在这，一放广告全回来
#     byteimg.com     -> *-ad-sign.byteimg.com 广告素材在这
#     bytedns1.com    -> 广告 CNAME 的落点，放了等于绕过拦截
#     cdngslb.com     -> 同上，共享 CDN 落点
#     volces.com      -> mssdk.volces.com 广告 SDK 在这
#     baidu.com       -> h2tcbox.baidu.com 是百青藤广告位
# ============================================================
