# 广告命名特征层 ad-signatures.txt
#
# 和黑名单的根本区别：blacklist-shared.txt 一行是一个「见过的域名」，
# 本文件一行是一类「命名结构」。广告方换编号（ads3 -> ads9）、换区域码
# （lq -> zz）、换 CDN 别名后缀（.queniurc.com -> .queniuzzz.com）、
# 换随机子域，只要命名结构不变，第一次出现就会被拦，不需要人工补名单，
# 也不需要先在日志里见过它。这是对「名单更新速度赶不上换域名速度」的
# 结构性答复：不再追域名，改为一次写好判定特征。
#
# 语法沿用规则引擎：* 匹配一段不含点的字符串，** 匹配任意字符（含点）。
# 优先级：force-block > whitelist > 本文件 > blacklist > blacklist-shared。
# 白名单仍最高优先，避免特征写宽时误伤系统 / 金融 / 业务域。
#
# 回放依据：2026-11-04 ~ 11-10 线上 1005122 条查询、7229 个从未被拦的
# 业务域。以下每条特征对业务域 0 命中；命中到的放行域全部是
# 「规则生效前的历史漏网广告域」，属于补漏收益而非误伤。
# 体检与自动归纳：python3 signature_report.py [--auto]
#
